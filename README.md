# Barbearia-Urban
Landing page ficticia moderna e responsiva desenvolvida para a Barbearia Urban, com foco em apresentação dos serviços, identidade visual, experiência do usuário e conversão de visitantes em clientes. Projeto desenvolvido com HTML, CSS e JavaScript.

# 💈 Barbearia Urban

Landing page moderna e responsiva desenvolvida para a **Barbearia Urban**, com foco em apresentar a identidade da marca, serviços oferecidos e proporcionar uma experiência de navegação simples, elegante e intuitiva.

## 🚀 Sobre o projeto

O projeto foi desenvolvido como uma página institucional para uma barbearia, priorizando:

* 🎨 Design moderno e profissional
* 📱 Responsividade para diferentes dispositivos
* ⚡ Navegação rápida e intuitiva
* 💈 Apresentação dos serviços
* 📞 Facilitação do contato com o cliente
* ✨ Experiência visual alinhada ao segmento de barbearia

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Design responsivo
